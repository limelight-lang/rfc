04 · Owner commit

Finalization

Это не обычный free(). Порядок защищает от weak-reference resurrection, повторного teardown и пользовательского кода, который создаёт новый внешний hold.

01

Zero-count check

Компонент с уже завершённым обычным teardown исключается из batch.

02

Exact validation

Owner перечитывает текущие fields и вычисляет актуальный RC − IN.

03

Guard +1

Каждый member получает временный strong hold против re-entrant teardown.

04

Weak invalidation

Все weak cells всех members очищаются до первого вызова user code.

05 · USER CODE

__destruct

Destructor может store, allocate, release или resurrect компонент.

06

Revalidate

Если destructor создал внешний hold, guards снимаются, компонент остаётся жить.

07

Sever edges

Internal slots обнуляются; external children временно откладываются.

08

Reclaim

Снять guards, вернуть slots, затем release deferred external children.

◆
Ownership invariantТолько owning mutator может очистить candidate bit, удалить queue entry или вернуть slot для повторного использования.
05 · Design debt

Что ещё не замкнуто

Синхронный owner-side путь — минимальная реализация. Collector worker требует дополнительных протоколов, которые нельзя заменить одной memory-order аннотацией.

A1 · MEMORY SAFETY

Concurrent slot reads

Pointer и 16-byte ValueBox slots не имеют безопасного off-thread read protocol. Нужны atomics, seqlock/versioning, barrier snapshot или stop-at-consistent-point.

A2

Queue swap

Не определён linearization point между worker swap и concurrent registration.

A3

Slot reuse

Owner-observed token release и worker release store пока задают разные моменты возврата slot.

A4

Block migration

abandon/adopt может передать block, пока старый trace держит его shadow rows.

A5

Finite overflow

Размер mandatory candidate capacity не выведен из строгого poll bound.

A6 · LIFETIME

Validation batch переживает trace arena

При token release scratch arena сбрасывается, но exact validation всё ещё нужны member lists. Нужна отдельная owner-owned arena или detached allocation.
